# reports (legacy samples)

Older reference outputs, kept for history. None of them is in the canonical v2.1 format, and none passes `render_report.py --check`.

| File | Format |
|---|---|
| `marc-chalme-artist-report.json` | Legacy v0.1 JSON (`product-spec/artist-report-schema-v0.1.json`). Migrated version: `examples/marc-chalme-20260805/report.json`. |
| `marc-chalme-artist-report.md`, `marc-chalme-artist-report-zh.md` | v0.1 Markdown renderings of the same research (en / zh). |
| `hiroshi-sugimoto-artist-report.md`, `hiroshi-sugimoto-artist-report-zh.md` | Markdown only; no JSON or image assets. This is the design lineage for the visual standard. |

New reports belong in `artist-reports/<artist-slug>-<YYYYMMDD>/` (see `skills/artist-report/SKILL.md`).
